# 🧩 万象归形（Wanxiang Guixing）

面向 Pico Neo3 的 WebXR 3D 拼图游戏：把散落在斜坡上的碎片拼回悬浮的虚影模型。
20 个模型 / 96 个关卡 / 5 档难度 / 7 套配色 / 6 套场景主题 / 13 个成就，
完整离线可玩（浏览器 HTTPS、单文件 HTML、独立 APK 三种形态）。

> 作者：**ZhaoZehao10** · GitHub: <https://github.com/ZhaoZehao10>
> 许可证：[MIT](LICENSE)（第三方依赖 three.js r160 亦为 MIT）

## 🚀 快速开始

### 1. 启动服务器（电脑上）

```powershell
node make-cert.mjs      # 首次：生成本地 CA + 服务器证书（cert/）
node server.mjs         # HTTPS 8443 / HTTP 8081
```

### 2. 头盔访问

- 头显浏览器打开 `https://<电脑局域网IP>:8443/`
- 首次建议先装 CA：`http://<IP>:8081/ca.crt`（设置→安全→从存储安装），之后 HTTPS 零警告
- 不急也可以：HTTPS 页面点「高级」→「仍要继续」

### 3. 三种形态

| 形态 | 产物 | 说明 |
|------|------|------|
| 局域网 HTTPS | `node server.mjs` | Pico 浏览器直接打开，最方便 |
| 单文件离线版 | `dist/WanxiangGuixing-offline.html` | three.js/VRButton/全部模块内联，拷到头盔或 U 盘即可 |
| 独立 APK | `dist/WanxiangGuixing.apk` | 免电脑：内置页面服务（127.0.0.1:8898）+ 自动拉起浏览器 |
| 在线游玩 | <https://zhaozehao10.github.io/wanxiang-guixing-vr/> | GitHub Pages 自动部署，Pico 浏览器直接打开（HTTPS） |

## 🎮 玩法

| 操作 | 说明 |
|------|------|
| 扣扳机 | 抓取/释放碎片（双手可各拿一块） |
| 摇杆 | 旋转手中碎片（左右/前后） |
| 握键 | 空手=开/关 VR 菜单；拿着碎片=送回散落点 |
| 自动吸附 | 位置与朝向都接近虚影目标位姿时，松手平滑吸附 |
| 抓取高亮 | 抓起碎片时，虚影中对应块亮绿显示 |
| 磁吸辅助 | 接近目标位姿时轻拉对齐（可在设置里调强度） |
| 提示 | 5 秒内自动提示一次；卡住 25 秒自动再提示 |

- **难度**：2 块（入门）/ 3 块（进阶）/ 4 块（挑战）/ 6 块（大师）/ 8 块（极限）
- **关卡**：20 模型 × 4 档 + 16 模型 × 8 块 = **96 关**（圣诞树/小猪/青蛙/甜甜圈 8 块经全轴向组合与单轴平行切割均无解，属几何限制，菜单中自动置灰）
- **星级**：按用时相对 par 时间给 1~3 星（2:90s / 3:160s / 4:260s / 6:380s / 8:520s）
- **本地记录**：每关星级 / 最佳时间 / 游玩次数 / 前三最佳成绩
- **每日挑战**：按日期确定性选模型+难度，菜单顶部一键开局（离线可用）；每日挑战榜显示本地前三与连续天数
- **练习模式**：不计时、不记录成绩与成就
- **成就（11 个）**：初次拼合 / 入门全通 / 模型收藏家 / 独立思考 / 极速拼手 / 大师挑战 / 极限初体验 / 极限大师 / 星光收集者（50 星）/ 极限三连（3 个模型 8 块三星）/ 完美主义
- **VR 内菜单**：开始 / 提示 / 配色 / 音乐 / 进度（进度页含关卡、星星、成就与当前模型记录）
- **手感/画面设置**：磁吸强度、震动强度、VR 菜单距离与大小；渲染比例、星空、桌面高度、音乐/音效音量、语言（封面「⚙️ 手感设置」）
- **存档备份**：一键导出/导入进度、成就与设置（JSON），换设备不丢档；支持复制诊断信息
- **随机模式**：每局随机生成切割平面（运行时水密校验，失败自动回退），不记录成绩
- **模型图鉴**：18 个模型收集进度一览，点击直接开局
- **双人轮流**：同一头显两人轮流拼同一关（1 局 / 3 局 2 胜），自动比较用时与星级
- **完成海报**：结算一键生成 PNG 海报（模型/星级/用时/日期）
- **中英双语**：核心界面支持中文 / English 切换（设置面板）
- **统计面板**：总进度/星星/最佳总时长/成就/每日挑战连续天数/模型收集一览
- **无障碍**：界面缩放（标准/大/特大）、菜单位置（左/中/右）、高对比配色
- **场景主题**：夜空 / 雪夜 / 日落 / 樱花 / 深海 / 黄昏；配色 7 套：经典 / 霓虹 / 暖冬 / 冷银 / 节日 / 海洋 / 高对比
- **排行榜**：菜单「🏆 排行榜」分「本模型 / 全模型总榜 / 今日挑战」三页：总进度/总星数/最佳总时长、当前模型各难度前三、各难度全模型最快前三、今日挑战本地前三
- **上手引导**：首次从菜单开局时展示 4 步操作说明（只出现一次，可跳过）

## 🏗️ 技术实现

- **真实切割**：模型沿轴对齐平面剖分，跨面三角形按交线拆分，交点按边端点对去重，
  两侧立即补平面封盖（边界闭环行走 + 耳切三角化），中间块封盖会被后续切割干净剖分。
- **运行时断言**：每片输出前做有向边普查（水密性）、体积为正、总体积守恒（<0.5%）。
- **切割表**：`tools/calibrate-cuts.mjs` 自动标定 20 模型 × 5 档共 96 组合，
  按最小刀距阶梯搜索（14%→10%→7%→5%）；结果写入 `puzzle.mjs` 的 `CUT_TABLE` 标记区。
- **零外部依赖**：three.js r160 + VRButton 已本地化，运行时无任何外网请求。
- **画质自适应**：按帧率在 3 档间调整像素比与星空，Pico Neo3 72Hz 目标。
- **程序化音频**：吸附/抓取/胜利音效与 Am-F-C-G 背景 Pad 全部 WebAudio 实时合成。

## 📦 构建

```powershell
# 单文件离线版
node tools\make-offline-puzzle.mjs        # → dist\WanxiangGuixing-offline.html

# APK（无 Gradle：aapt2 → javac → d8 → zipalign → apksigner）
powershell -File tools\build-apk-puzzle.ps1   # → dist\WanxiangGuixing.apk
```

APK 壳工程在 `apk-puzzle/`（包名 `com.zhaozehao.wanxiangguixing`、端口 8898、独立 keystore 与图标），
首次安装需在 Pico 设置 → 安全 中允许未知来源。

```powershell
# 安装到头盔
android-sdk\platform-tools\adb.exe install -r "dist\WanxiangGuixing.apk"
```

## 🩺 真机排查

完整真机验收清单（安装/手柄/追踪/舒适度/性能/数据/异常）见 [docs/DEVICE-CHECKLIST.md](docs/DEVICE-CHECKLIST.md)。

| 现象 | 处理 |
|------|------|
| 看不到 ENTER VR | 封面点「🔍 设备自检」看 `immersive-vr`；`file://` 打开会显式警告，改用 APK 或 HTTPS |
| 进 VR 后黑屏 / 切应用回来黑屏 | 覆盖层点「重新加载」，进度已本地保存 |
| 手柄扣扳机没反应 | 确认已进入 VR；扣扳机=抓取，握键=菜单，摇杆=旋转 |
| 菜单太大/太近 | 「⚙️ 手感设置」调 VR 菜单距离/大小 |
| 震动太强/没有 | 「⚙️ 手感设置」调震动强度 |
| 对准太难/太黏 | 「⚙️ 手感设置」调磁吸强度 |
| 帧率不稳 | 画质自适应自动降级；减少同时手持碎片 |
